# 실물 4세대 카트 없이 포켓시프터 쓰기 (DSpico)

> **실험 기능입니다.** 시작하기 전에 4세대 세이브 파일(`.sav`)을 꼭 백업하세요.

포켓몬스터 블랙·화이트의 **포켓시프터**는 다른 DS에 꽂힌 4세대 카트(DP·Pt·HGSS)에서 포켓몬을 옮겨 옵니다.
이 Pico Loader는 DSpico를 쓰는 DSi가 SD 카드의 4세대 롬과 세이브를 **실물 카트로 보이게** 합니다. 실물 4세대 카트 대신 포켓시프터를 쓸 수 있습니다.

동작 방식:
1. Pico Loader가 DSi의 "DS 다운로드 플레이"(`dlp.nds`)를 실행합니다.
2. 블랙·화이트에서 포켓시프터를 실행하고 다른 실기에서 다운로드 받아주세요.
3. 받은 프로그램이 시작되기 직전에 Pico Loader가 패치를 적용합니다. 

## 준비물

| 무엇 | 설명 |
|---|---|
| 받는 쪽 기기 | **DSi** + DSpico(Pico Launcher) |
| 보내는 쪽 기기 | 블랙·화이트 카트가 꽂힌 DS / DSi / 3DS 한 대 |
| `dlp.nds` | **본인 DSi**에서 뽑은 "DS 다운로드 플레이" 앱. 배포하지 않습니다.
| 4세대 롬 | 본인 카트에서 뽑은 DP·Pt·HGSS 롬(`.nds`) |
| 4세대 세이브 | 롬과 **같은 폴더, 같은 이름**의 `.sav` (예: `/nds/플래티나.nds` → `/nds/플래티나.sav`) |
| 패치 Pico Loader | DSPICO용 빌드(`Pico_Loader_DSPICO`) |

## 1. Pico Loader 바꾸기

1. SD 카드의 `/_pico` 폴더를 통째로 백업해 둡니다.
2. 이 저장소의 Releases(또는 Actions)에서 `Pico_Loader_DSPICO`를 받습니다.
3. 받은 파일을 SD 카드의 `/_pico`에 덮어씁니다.
   - `picoLoader7.bin`
   - `picoLoader9.bin`
   - `aplist.bin`, `patchlist.bin`, `savelist.bin`

원래대로 돌리려면 백업한 `/_pico`의 파일을 다시 덮어쓰면 됩니다.

## 2. `dlp.nds` 준비

뽑은 파일은 `dlp.nds`라는 이름으로 SD 카드의 아무 폴더에나 둡니다(예: `/nds/dlp.nds`).

## 3. `/_pico/dlpcart.txt` 만들기

카트로 보일 4세대 롬의 경로를 **첫 줄**에 적습니다.

```
/nds/포켓몬스터_기라티나.nds
```

- 경로는 SD 카드 맨 위(`/`)부터 적습니다.
- 메모장으로 저장해도 됩니다(UTF-8). 한글 파일 이름도 됩니다.
- .sav 파일이 준비되어 있는지 확인해주세요.

## 4. 포켓시프터 실행

1. 보내는 쪽(블랙·화이트): 메뉴에서 포켓시프터를 시작하고 받는 쪽을 기다리게 합니다.
2. 받는 쪽(DSi + DSpico): Pico Launcher에서 `dlp.nds`를 실행합니다.
   - 롬이나 세이브에 문제가 있으면 다운로드 전에 이 단계에서 오류가 납니다(아래 표 참고).
3. 목록에 나온 포켓시프터를 골라 받습니다.
4. 닌텐도 로고 뒤에 흰 화면이 몇 초 이어집니다. 이때 Pico Loader가 다시 들어오는 중이니 기다리세요.
5. 4세대 게임의 박스 화면이 나오면 평소처럼 포켓몬을 골라 보냅니다.
6. 보내기가 끝나면 받는 쪽이 SD의 `.sav`에 저장합니다. 저장이 끝날 때까지 전원을 끄지 마세요.

다운로드 직후 통신 에러가 가끔 납니다. 다시 하면 대부분 됩니다.

## 오류 메시지

| 메시지 | 원인과 해결 |
|---|---|
| `Failed to open the card rom file.` | `dlpcart.txt`에 적은 롬이 없습니다. 경로와 파일 이름을 확인하세요. |
| `No card rom path in /_pico/dlpcart.txt.` | `dlpcart.txt` 첫 줄이 비어 있습니다. |
| `The card rom path is too long.` | 롬 경로가 너무 깁니다. 짧은 폴더나 이름으로 옮기세요. |
| `The card rom file is too fragmented.` | 롬 파일이 SD 카드에서 너무 여러 조각으로 나뉘어 있습니다. 롬을 PC로 옮겼다가 다시 복사하거나, SD 카드를 포맷한 뒤 다시 복사하세요. |
| `Failed to setup save file.` | 세이브 파일이 너무 조각나 있거나 만들 수 없습니다. 위와 같이 다시 복사하세요. |

## 확인된 범위

| 보내는 쪽 | 받는 쪽 4세대 롬 | 결과 |
|---|---|---|
| 한국판 블랙 | 한국판 플래티나(`CPUK`) | 전송·저장 됨 |
| 한국판 블랙 | 한국판 소울실버(`IPGK`) | 전송·저장 됨 |

받는 쪽 기기: 한국판 DSi + DSpico(공식 펌웨어 v1.0.x), 한국판 `dlp.nds`(`HNDK`).

아직 확인하지 않은 것:
- 화이트, 블랙2·화이트2, 다른 언어판 블랙·화이트
- 다른 지역 DSi의 `dlp.nds`
- DS Lite나 3DS를 받는 쪽으로 쓰는 경우
- DSpico가 아닌 플래시카트
